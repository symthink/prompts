# Vision prompts

Prompts for working on a personal reasoning tree ("My Vision" in Symthink). A tree is made of
Questions ❓, Ideas 💡, and Claims 🕫. These prompts take a node plus the nodes around it and ask
an AI to teach, research, or turn an outside source into a new tree.

## How these prompts are delivered

Everything here is **`external-chat`**: the person copies the rendered prompt into the AI chat
of their choice (ChatGPT, Claude, Gemini, …). Research and import prompts end with a
**paste-back contract**, so the AI replies with one fenced markdown outline that Symthink can import
as tree nodes. Learning with AI is a conversation and has no paste-back.

Import from `@symthink/prompts/external-chat`.

## Prompt details

### civic-level-research

Guides a two-phase conversation that explores a level of government in the user's jurisdiction, then pastes back a set of Questions under that civic-level node.

- **Id:** `vision.civic-level-research`
- **Template:** [`prompt.md`](./civic-level-research/prompt.md) · [`meta.json`](./civic-level-research/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** yes
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/src/utils/civicLevelAiResearchContext.helpers.ts (buildCivicLevelResearchPrompt)`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/my-vision-options-menu.md`
- **Notes:** Paste-back is Questions only. The root bullet gets a ❓ marker when the question text has none.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `levelLabel` | `string` | yes | Tree label of the civic-level node (e.g. `State`, `SLD Upper Chamber`). |
| `semanticType` | `string` | yes | Civic scope key of the level (e.g. `state`, `county`). |
| `jurisdiction` | `{ placeName, districtNumber?, stateCode? }` | no | Resolved place for this level. Omit when the civic ladder has no data; the prompt then tells the AI not to invent place names. |
| `questionText` | `string` | yes | Current text of the civic-level Question, with tree markers already replaced by punctuation (❓ → ?). The root bullet gets a ❓ appended unless the text already contains one. |

### import-from-source

Asks an external AI to read an article, podcast, or video and extract its most compelling argument as a Symthink tree for paste-back.

- **Id:** `vision.import-from-source`
- **Template:** [`prompt.md`](./import-from-source/prompt.md) · [`meta.json`](./import-from-source/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** yes
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/src/prompts/importFromArticle.ts`, `symthink-io/src/utils/importFromArticlePrompt.builder.ts`, `symthink-io/src/utils/pasteBackContract.helpers.ts`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/my-vision-options-menu.md`
- **Notes:** Pasted tree is attached as a new child of the Options subject (not flattened onto it).

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `articleUrl` | `string (URL)` | yes | Normalized http(s) URL of the source to read. |

### learning-with-ai

Copy-paste tutor prompt that helps a person learn the concepts behind a Question in their reasoning tree, iteratively and with knowledge checks.

- **Id:** `vision.learning-with-ai`
- **Template:** [`prompt.md`](./learning-with-ai/prompt.md) · [`meta.json`](./learning-with-ai/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/src/prompts/learningWithAi.ts`, `symthink-io/src/utils/learningWithAiPrompt.builder.ts`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/learning-with-ai.md`
- **Notes:** Copy-only workflow; there is no paste-back step.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `situationPreface` | `string` | no | Optional civic context lines (e.g. level of government and place) shown before the tree context. |
| `ancestorLines` | `string[]` | no | Ancestor nodes from tree root to parent, each formatted as `label: text`. |
| `questionText` | `string` | yes | The Question being explored. |
| `childLines` | `string[]` | no | Direct children of the Question (unverified notes), each formatted as `label: text`. |

### research

Generic research prompt for an Idea, Claim, or Question in the user's tree, with a paste-back step that nests new points under the current node.

- **Id:** `vision.research`
- **Template:** [`prompt.md`](./research/prompt.md) · [`meta.json`](./research/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** yes
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/src/utils/ai.store.ts (buildResearchPrompt, assembleResearchPromptBody)`, `symthink-io/src/utils/pasteBackContract.helpers.ts`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/my-vision-options-menu.md`
- **Notes:** The root bullet is the current node text with its type marker appended when missing.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `nodeType` | `"question" \| "idea" \| "claim"` | yes | Type of the node being researched; changes the framing, closing ask, and root marker. |
| `ancestorLines` | `string[]` | no | Ancestor nodes from tree root to parent, each formatted as `label: text`. |
| `currentText` | `string` | yes | Text of the node being researched. |
| `childLines` | `string[]` | no | Text of the node's direct children. |
