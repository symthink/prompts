# Article prompts

Prompts for turning a reasoning tree into writing. They run as a two-step conversation: editorial
analysis reviews a Question branch for gaps and scores how ready it is to become an article, then
the draft prompt, sent in the same chat, writes the strongest article that reasoning honestly
supports.

## How these prompts are delivered

Both prompts are **`external-chat`**. The author (or a subscriber reading a published tree) copies
the analysis prompt, which already contains the tree as YAML, into their own AI chat, then sends
the draft prompt as the next message. Nothing is pasted back into Symthink.

Import from `@symthink/prompts/external-chat`.

## Contributing

See [CONTRIBUTING.md](../../CONTRIBUTING.md). Keep these prompts audience-neutral and make the
audience a variable, as `editorial-analysis` does with `audience`.

## Prompt details

### draft

Prompt 2 of evidence-aware article drafting, sent in the same chat after the editorial analysis: writes the strongest article the reasoning honestly supports, with inline editorial-gap annotations.

- **Id:** `articles.draft`
- **Template:** [`prompt.md`](./draft/prompt.md) · [`meta.json`](./draft/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/src/prompts/articleDraft.ts`, `symthink-io/src/utils/articlePrompt.builder.ts (generateArticlePrompt)`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/evidence-aware-article-drafting.md`
- **Notes:** Context-free: relies on the tree and analysis from Prompt 1 earlier in the same conversation.

_No variables — the prompt is static._

Prompt 1 of evidence-aware article drafting: an editorial analyst assesses a YAML Question branch for gaps and scores its article readiness.

- **Id:** `articles.editorial-analysis`

- **Output:** `single` (returns one string)
