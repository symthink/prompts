# In-app prompts

Short, single-purpose model calls that run inside Symthink: rephrasing a node, labelling nodes,
pulling citation details out of a PDF, and summarizing a legislator's bills. Each one does a
small job and returns structured output for the app to use directly.

## How these prompts are delivered

**`symthink-api`** only. Every prompt returns a `{ system, user }` pair for a chat-completion call.
Some are kept as **`reference`** prompts: Symthink no longer calls them, but they stay here because
others may find them useful.

Import from `@symthink/prompts/symthink-api`.

## Contributing

See [CONTRIBUTING.md](../../CONTRIBUTING.md). Keep these prompts small. When a prompt grows into a
workflow with its own domain language (ballot, civic areas, …), give it its own domain folder.

## Prompt details

### labels

Generates a short (max 30 character) sentence-case label for each tree node in one call.

- **Id:** `in-app.labels`
- **Template:** [`system.md`](./labels/system.md), [`user.md`](./labels/user.md) · [`meta.json`](./labels/meta.json)
- **Output:** `system_user` (returns `{ system, user }`)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/supabase/functions/_shared/ai/capabilities/labels.ts (MULTI_LABEL_SYSTEM_PROMPT, makeLabelsInline)`

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `items` | `{ id: string, text: string }[]` | yes | Nodes to label; text is sent as YAML double-quoted strings. |

- **Id:** `in-app.rephrase`
- **Template:** [`system.md`](./rephrase/system.md), [`user.md`](./rephrase/user.md) · [`meta.json`](./rephrase/meta.json)

### rephrase-options

Returns three type-aware rephrasings of a tree node (questions stay questions, claims stay declarative, ideas stay tentative) as JSON.

- **Id:** `in-app.rephrase-options`
- **Template:** [`system.md`](./rephrase-options/system.md), [`user.md`](./rephrase-options/user.md) · [`meta.json`](./rephrase-options/meta.json)
- **Output:** `system_user` (returns `{ system, user }`)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/supabase/functions/_shared/ai/capabilities/rephrase.ts (buildRephraseSystemPrompt, getRephraseOptions)`
- **Notes:** symthink-io joins the system prompt into one paragraph; this template puts the type-specific rule on its own line. symthink-io fixes the limit at 280 characters (and truncates longer options); here it is the `maxChars` variable, defaulting to 280.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `nodeType` | `"question" \| "claim" \| "idea"` | yes | Node type; selects the tone rules. |
| `text` | `string` | yes | Text to rephrase (sent JSON-encoded in the user message). |
| `maxChars` | `number` | no | Maximum characters per option. Default 280. |
