# Civic area prompts

Prompts that explain a civic geographic scope (a county, a state legislative district, a school
district, …) to the residents who live in it: what the scope controls, who decides, and how a
resident can take part. The input is structured identifiers for one scope on Symthink's Civic
Ladder, so the model researches that exact place rather than guessing.

## How these prompts are delivered

Both prompts are **`symthink-api`**. Symthink's server sends the orientation prompt to a model with
web search and expects one JSON object back. If that JSON fails to parse, the server sends the
repair prompt as a follow-up turn.

Import from `@symthink/prompts/symthink-api`.

## Contributing

## Prompt details

### orientation

Web-search prompt that explains one civic scope on the user's Civic Ladder (what is distinctive, what it controls, who decides, how to participate) and returns structured JSON.

- **Id:** `civic-areas.orientation`
- **Template:** [`prompt.md`](./orientation/prompt.md) · [`meta.json`](./orientation/meta.json)
- **Output:** `single` (returns one string)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/supabase/functions/_shared/services/civic-area-orientation/prompt.ts (buildCivicAreaOrientationPrompt, PROMPT_VERSION civic-area-orientation-v3)`
- **Notes:** Sent to the OpenAI Responses API with web search. Variable names mirror the snake_case CivicAreaOrientationContext schema so the API context can be passed through unchanged.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `boundary_group_id` | `string` | yes | Civic area boundary group id. |
| `name` | `string` | yes | Civic area name. |
| `authoring_scope_key` | `string` | yes | Civic scope key (e.g. `sld_upper`, `county`). |
| `representation_topology` | `"coterminous_legislative_district" \| "single_representation_channel" \| "general_government_scope" \| "unspecified"` | yes | Selects the topology-specific research instructions. |
| `country` | `string` | yes | Country code or name. |
| `state_or_equivalent` | `string \| null` | no | State or equivalent; rendered as `(none)` when missing. |
| `level_display` | `string` | yes | Display name of the civic level. |
| `parent_areas` | `{ semantic_type, name }[]` | no | Parent civic areas. |
| `scope_identifiers` | `object` | no | Identifiers for this scope (rendered as JSON). |
| `ladder_members` | `{ semantic_type, name, civic_area_id, identifiers? }[]` | yes | Civic areas that share this scope on the ladder. |
| `representation_channels` | `{ representation_role, chamber?, district_code?, seat_count }[]` | no | Representation channels (chambers, districts, seats). |
| `additional_context` | `string` | no | Free-form additional context. |
