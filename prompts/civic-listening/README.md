# Civic listening prompts

Prompts that organize what a community said. Residents submit short, anonymous responses to a
civic question. Once enough responses arrive, a model groups them into themed Claims and keeps
the residents' own words as verbatim quote leaves under each theme.

## How these prompts are delivered

**`symthink-api`** only. Symthink's server renders a `{ system, user }` pair, where the user message
is a JSON payload of anonymous submissions, and the model replies with a Symthink JSON tree. The
`tier` variable switches between the 5+ submission rules (flat themes only) and the 20+ rules
(sub-themes allowed for broad themes).

Import from `@symthink/prompts/symthink-api`.

## Contributing

See [CONTRIBUTING.md](../../CONTRIBUTING.md). Submissions must be anonymized before rendering. Never
put names, emails, or other identifying details into fixtures.

## Prompt details

### synthesis

Clusters anonymous community submissions into a Symthink JSON tree of themed Claims with verbatim quote leaves.

- **Id:** `civic-listening.synthesis`
- **Template:** [`system.md`](./synthesis/system.md), [`user.md`](./synthesis/user.md) · [`meta.json`](./synthesis/meta.json)
- **Output:** `system_user` (returns `{ system, user }`)
- **Paste-back into Symthink:** no
- **Wired in Symthink from this package:** not yet
- **Symthink source:** `symthink-io/supabase/functions/_shared/civic-listening/synthesis-prompts.ts (buildPrompt)`, `symthink-io/supabase/functions/_shared/civic-listening/run-synthesis.ts`
- **Symthink docs:** `symthink-io/docs/developer-guide/systems/civic-listening.md`
- **Notes:** The user message is a JSON payload. This template pretty-prints it; symthink-io sends the same payload as compact JSON. The API also enforces JSON with response_format, and the server checks that quote leaves are verbatim.

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `tier` | `"5_plus" \| "20_plus"` | yes | `5_plus` allows flat categories only; `20_plus` allows sub-categories for broad themes. |
| `submissions` | `{ id: number, body: string }[]` | yes | Anonymous submissions with stable numeric ids the model references in metadata. |
